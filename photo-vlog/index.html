進階：Google API 金鑰（選填）

填入 Google Geocoding API 金鑰，就會改用 Google 定位地名；不填則使用 OpenStreetMap 免費查詢。金鑰只留在這次開啟的頁面，不會儲存。

03照片與定位

會自動讀取照片的拍攝日期與 GPS，再查詢地名與當天天氣。

iPhone 若讀不到位置：可能是上傳時移除了定位資訊。在選擇照片的畫面點「選項」開啟「位置」（依 iOS 版本而異），或在下方手動輸入地點。

    選擇小人物

    名字會顯示在地圖上小人物的頭頂，留白就不顯示。
    地圖樣式

    街道、地形圖、衛星使用真實圖資。手繪、卡通、像素、日系動畫會依照片座標讀取真實高度資料，畫出實際的海岸線與山形；離線時改用依路線生成的插畫島嶼。

    只輸出片尾的足跡地圖：影片含小人物走完全程的動畫，圖片是最後完整路線的畫面。

      07預覽與輸出

      輸出會即時播放整支影片並錄成影片檔，錄製期間請保持畫面開啟。
